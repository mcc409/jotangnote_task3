# Part 4：前端页面

### 1. 功能说明
为了方便直观地测试 JotangNote 的后端与 AI 功能，我利用 AI 辅助（Vibe Coding）生成了一个单页面的前端界面。该界面直接内置在 Spring Boot 的 `src/main/resources/static/` 目录下。

### 2. 页面功能与设计
页面采用了暗黑主题风格，分为左右两栏：
- **左侧（笔记管理）**：
  - 包含一个输入框和发布按钮，可以直接新建笔记。
  - 下方列表展示所有笔记，并显示笔记的 ID 和作者 ID，提供删除按钮。
- **右侧（AI 助手）**：
  - 模拟聊天对话框，带有 `sessionId`，支持连续对话。
  - 发送消息后，前端通过 `fetch` 请求 `/api/chat` 接口。由于后端接入了 Tool Use，AI 会自动去数据库查询笔记并返回给用户。

### 3. 前端核心逻辑（JavaScript）
前端主要通过原生的 `fetch` API 与后端进行数据交互。
例如新建笔记的请求：
```javascript
await fetch('/api/notes', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'userId': CURRENT_USER_ID // 模拟当前登录用户
    },
    body: JSON.stringify({ content: content })
});
// 因为后端使用了 RabbitMQ 异步处理，前端延时 500ms 后再刷新列表
setTimeout(loadNotes, 500);
```

调用 AI 助手的请求：

```javascript
const res = await fetch('/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        sessionId: "web_user_1",
        message: message
    })
});
const reply = await res.text();
loadingMsg.innerText = reply;
```
